End-to-end syllabus

Build the complete data pipeline.

Move from programming fundamentals to data modelling, cloud services, use cases, and production-style projects.

Python

  • Fundamentals and data types
  • Control flow and functions
  • File and exception handling
  • Object-oriented programming
  • Pandas data processing
  • APIs and JSON
  • Extract, transform, load
  • Reusable pipeline scripts

SQL

  • Fundamentals and CRUD
  • Functions and joins
  • Subqueries and CTEs
  • Window functions
  • Dynamic SQL and PL-SQL
  • Stored procedures
  • Query optimization
  • Performance tuning

Data Warehousing

  • Normalization
  • Fact and dimension tables
  • Star and snowflake schemas
  • Slowly changing dimensions
  • ETL and data quality
  • Scheduling and orchestration
  • Data modelling
  • Production pipeline patterns

Google Cloud

  • Cloud services theory
  • IAM and service setup
  • Cloud Storage
  • BigQuery
  • Pub/Sub and Dataflow
  • Cloud Composer
  • Use cases and programs
  • End-to-end project modules
